# Icon sources

- `docs/design/reference/assets/app-icon.svg` and `app-icon-1024.png` contain
  the original serif B monogram created for this project's design reference.
- `Sources/BBVA/Resources/BBVA-AppIcon.png` is a byte-identical copy of that
  original PNG. It replaces the formerly copied official BBVA México logo.
- `Sources/BBVA/Resources/BBVA.icns` packages mechanical PNG resizes of the
  original monogram for macOS; native resource names remain stable.
- The iOS app's existing background artwork remains repository-authored.

The repository-authored artwork is covered by the MIT license in `LICENSE`.
BBVA's name is its owner's trademark; this independent companion is not
endorsed by BBVA. No official BBVA application artwork is redistributed.
