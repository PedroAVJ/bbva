Item row inside a category detail: shade dot (from `ZoomShade`), name, "mo · day" with the per-day figure emphasized, bold percent of the category.

```jsx
<ItemRow name="Rent" mo="7,500" day="250" pct="83%" color={ZoomShade('var(--seg4)',0,3)} first />
```

Not clickable — items are the bottom of the aggregation hierarchy.
